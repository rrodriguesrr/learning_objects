1.0 Introdução

1.1 Definições

  • Baseado no Teorema de Bayes: Utiliza o teorema de Bayes para calcular a probabilidade posterior de cada classe, com base em observações independentes.
  • Suposição de Independência: Assume que os atributos que descrevem as instâncias são condicionalmente independentes entre si, dada a categoria da instância.
  • Versátil para classificação: Pode ser usado tanto para tarefas de classificação binária quanto multiclasse.
  • Eficiência: É particularmente conhecido por sua simplicidade e eficiência em conjuntos de dados de grande dimensão.
  • Flexibilidade para atributos contínuos e categóricos: Pode lidar com tipos de dados variados, aplicando diferentes formas de distribuição de probabilidade para atributos contínuos (como a Gaussiana) e tratando de maneira eficaz atributos categóricos.

1.2 Pontos Positivos

  • Eficiência na construção do modelo: Todas as probabilidades necessárias podem ser calculadas a partir do conjunto de treinamento em uma única passagem, tornando o processo de construção do modelo bastante eficiente.
  • Facilidade de implementação: O algoritmo é simples e pode ser implementado de forma incremental, o que é vantajoso para aplicações práticas.
  • Bom desempenho em vários domínios: Demonstrado por Domingos e Pazzani (1997), o naive Bayes apresenta um bom desempenho em uma grande variedade de domínios, incluindo aqueles com claras dependências entre atributos.
  • Correção na classificação baseada na ordenação das classes: O algoritmo consegue classificar corretamente os exemplos desde que a ordenação das classes pelas estimativas das probabilidades a posteriori esteja correta, mesmo que as estimativas não sejam realistas.
  • Robustez a ruídos e atributos irrelevantes: Kononenko (1991) destaca a robustez do classificador à presença de ruídos e atributos irrelevantes no conjunto de dados.
  • Facilidade de compreensão das teorias aprendidas: As teorias geradas pelo naive Bayes são facilmente compreendidas pelos especialistas do domínio, graças à simplificação dos dados em tabelas de contingência.
  • Desempenho não afetado por atributos irrelevantes: O desempenho do naive Bayes permanece estável mesmo na presença de atributos que não contribuem para a decisão, uma característica valiosa para a manutenção da precisão do modelo em cenários variados.

1.3 Pontos Negativos

  • Impacto negativo das variáveis redundantes: O Naive Bayes pode atribuir um peso maior do que o devido a atributos redundantes devido à sua suposição de independência entre os atributos. Isso pode levar a uma distorção na importância dada a esses atributos nas decisões do modelo.
  • Tratamento ineficiente de atributos contínuos: O classificador exige que os atributos contínuos sejam discretizados ou que se assuma uma distribuição de probabilidade específica para eles (geralmente, a gaussiana). Essa abordagem pode não ser adequada se os atributos não seguirem a distribuição assumida, impactando negativamente a precisão do modelo.
  • Estimativas de probabilidade não realistas: Embora o Naive Bayes frequentemente produza estimativas de probabilidade que não são realistas, ele ainda é capaz de fornecer um bom ranqueamento das classes. Isso indica uma limitação na interpretação das probabilidades absolutas geradas pelo modelo, embora sua capacidade de classificação permaneça eficaz.

2.0 Base de Dados

Para este experimento, vamos utilizar a base de dados “Iris flower”. Esses conjuntos de dados consistem em 3 tipos diferentes de comprimento de pétala e sépala de íris (Setosa, Versicolour e Virginica), armazenados em um numpy.ndarray de 150 x 4

As linhas são as amostras e as colunas são: Comprimento da Sépala, Largura da Sépala, Comprimento da Pétala e Largura da Pétala.

  • 50 amostras de 3 espécies diferentes de íris (total de 150 amostras)
  • Medidas: comprimento da sépala, largura da sépala, comprimento da pétala, largura da pétala
  • O formato dos dados: (comprimento da sépala, largura da sépala, comprimento da pétala, largura da pétala)

Descrição: * sepal_length: Comprimento da sépala, em centímetros, usado como entrada. * sepal_width: Largura da sépala, em centímetros, usada como entrada. * petal_length: Comprimento da pétala, em centímetros, usado como entrada. * petal_width: Largura da pétala, em centímetros, usada como entrada. * classe: Iris Setosa, Versicolor ou Virginica, usada como alvo.

2.3 Análise Exploratória dos dados

Box plot

Um boxplot (ou diagrama de caixa, numa tradução livre) mostra a distribuição quantitativa dos dados de um jeito que facilita a comparação entre as variáveis, ou através dos níveis categóricos das variáveis.

Essa caixa (“box”) mostra os quartis do dataset enquanto os “whiskers” mostram o resto da distribuição, exceto os pontos que são chamados de outliers.

plt.figure()

Gráfico de coordenadas paralelas.

Para dados não tão densos, uma forma de observar a relação entre classes é através do gráfico de coordenadas paralelas.

Violin

Violin Plot é um método para visualizar a distribuição de dados numéricos de diferentes variáveis. É semelhante ao Box Plot, mas com um gráfico girado em cada lado, fornecendo mais informações sobre a estimativa de densidade no eixo y. A densidade é espelhada e invertida e a forma resultante é preenchida, criando uma imagem semelhante a um violino. A vantagem de um gráfico de violino é que ele pode mostrar nuances na distribuição que não são perceptíveis em um boxplot. Por outro lado, o boxplot mostra mais claramente os outliers nos dados.

4.0 Building the Naive Bayes Model

A bit of the concept of the Naive Bayes algorithm with StatsQuest

HTML('<iframe width="642" height="361" src="https://www.youtube.com/embed/O2L2Uv9pdDA" title="Naive Bayes, Clearly Explained!!!" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen></iframe>')

Naive Bayes is a classification algorithm used for both binary (two-class) and multi-class classification problems. The technique is easier to understand when described using binary or categorical input values..

It is called Naive Bayes or Idiot Bayes because the calculation of probabilities for each hypothesis is simplified to make the computation manageable. Instead of trying to calculate the joint probability of each attribute value \(P(d1, d2, d3|h)\), the attributes are considered conditionally independent given the target value and are calculated as \(P(d_1|h) \cdot P(d_2|h)\), and so on.

This is a very strong assumption, which is unlikely to hold in real-world data—specifically, that the attributes do not interact. However, the approach works surprisingly well even on data where this assumption does not hold.

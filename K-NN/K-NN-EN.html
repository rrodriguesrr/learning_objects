1.0 Introduction

The K-Nearest Neighbors (KNN) model is a machine learning algorithm used for both classification and regression tasks. It is one of the simplest and most intuitive methods for classifying new data points based on their proximity to existing examples.

The functioning of KNN is straightforward. It stores a set of labeled training data and, when presented with a new unlabeled example, it searches for the k nearest neighbors within the training set. The distance between points is calculated using a metric, such as the Euclidean distance, and the k closest neighbors are selected.

For classification tasks, the most common label among the k neighbors is assigned to the new example. For regression tasks, the average of the labels of the k neighbors is used as the predicted value for the new example.

The value of k is a crucial parameter in KNN. A smaller k value makes the model more sensitive to noise and fluctuations in the data, while a larger k value smooths the decision boundaries but may lose finer details.

KNN has some limitations, such as the need to keep the entire training set in memory to perform nearest neighbor queries, which can be computationally expensive for large datasets. Additionally, the appropriate choice of distance metric and k value is critical for achieving accurate results.

In summary, KNN is a simple yet effective machine learning algorithm that classifies new examples based on their proximity to training examples, making it suitable for both classification and regression problems.

1.1 Definitions

  • K-NN is a predictive model method based on distance.
  • It considers the proximity between data points to make predictions.
  • It operates on the assumption that similar data tends to cluster in the same region.
  • Variations are determined by the number of neighbors considered.
  • The most commonly used metric is the Euclidean distance.

1.2 Pros

  • Simple training algorithm.
  • implification of the objective function for optimization.
  • Applicable to both simple and complex problems.
  • Incremental algorithm for training purposes.

1.3 Cons

  • Higher computational effort during the training phase.
  • To classify a new observation, it requires calculating the distance between this object and all training objects.

2.0 Database

For this experiment, we will use the “Iris flower” dataset. This dataset consists of 3 different types of iris petal and sepal lengths (Setosa, Versicolor, and Virginica), stored in a 150 x 4 numpy.ndarray.

The rows represent the samples, and the columns are: Sepal Length, Sepal Width, Petal Length, and Petal Width.

  • 50 samples from 3 different iris species (a total of 150 samples)
  • Measurements: sepal length, sepal width, petal length, petal width
  • Data format: (sepal length, sepal width, petal length, petal width)

Description: * sepal_length: Sepal length, in centimeters, used as an input. * sepal_width: Sepal width, in centimeters, used as an input. * petal_length: Petal length, in centimeters, used as an input. * petal_width: Petal width, in centimeters, used as an input. * class: Iris Setosa, Versicolor, or Virginica, used as the target.

Box plot

A boxplot (or box-and-whisker plot) displays the quantitative distribution of data in a way that facilitates comparison between variables or across the categorical levels of variables.

This “box” represents the quartiles of the dataset, while the “whiskers” show the rest of the distribution, except for the points that are considered outliers.

Parallel Coordinates Plot.

For less dense data, one way to observe the relationship between classes is through a parallel coordinates plot.

This type of visualization is used to plot multivariate numerical data. Parallel Coordinates Plots are ideal for comparing many variables together and seeing the relationships between them. For example, if you needed to compare a variety of products with the same attributes (such as comparing computer or car specifications across different models).

from sklearn.neighbors import KNeighborsClassifier

4.3 Finding the Optimal Number of K-Neighbors

# creating list of K for KNN
k_list = list(range(1,50,2))
# creating list of cv scores
cv_scores = []

# perform 10-fold cross validation
for k in k_list:
    knn = KNeighborsClassifier(n_neighbors=k)
    scores = cross_val_score(knn, X_train, y_train, cv=10, scoring='accuracy')
    cv_scores.append(scores.mean())
# changing to misclassification error
MSE = [1 - x for x in cv_scores]

plt.figure()
plt.figure(figsize=(15,10))
plt.title('The optimal number of neighbors', fontsize=20, fontweight='bold')
plt.xlabel('Number of Neighbors K', fontsize=15)
plt.ylabel('Misclassification Error', fontsize=15)
sns.set_style("whitegrid")
plt.plot(k_list, MSE)

plt.show()
<Figure size 432x288 with 0 Axes>
# finding best k
best_k = k_list[MSE.index(min(MSE))]
print("The optimal number of neighbors is %d." % best_k)
The optimal number of neighbors is 9.
